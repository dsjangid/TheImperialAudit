# Changelog — The Imperial Audit

## [2.1.0] - 2026-11-02

### Added
- Dedicated standalone archival record pages (`/en/records/[id]`) for all 13 primary documents.
- Minimalist inline language switcher (`EN / BN / HI`) with localStorage persistence and HTML `lang` sync.
- Comprehensive localization dictionaries for English, Bengali (বাংলা), and Hindi (हिन्दी).
- Schema.org / JSON-LD structured metadata generation for archival records.
- High-contrast keyboard focus styling and reduced-motion protections.
- Dedicated clean print media stylesheet for document archiving.
- Automated test runner and 7 verification scripts.

### Changed
- Replaced modal popup with full dedicated record reader views.
- Streamlined header into prominent bold title with slide-out numbered chapter drawer.
- Removed box-like backgrounds across hero and monograph sections in favor of clean typographic rules.
- Restored native OS cursor.

### Removed
- Removed intrusive modal popups (`SourceViewerModal`).
- Removed decorative eye illustration and case-opener transition.
- Removed corner badges and wayfinder floating widgets.
- Removed bracketed `[ INDEX ]` navbar wording.
